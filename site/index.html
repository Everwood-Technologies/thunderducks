🦆 Thunderducks

Get started Docs GitHub

Event-driven E2EE chat.
P2P-first. No tokens.

Thunderducks is a federated hybrid P2P messenger with end-to-end encryption for 1:1 and groups, multi-device identity, developer widgets, and an optional untrusted relay assist. Relays never get a plaintext API.

View on GitHub Read the docs

What it is

  • Signed events + per-room causal DAG
  • vodozemac Olm / Megolm (1:1 + groups)
  • Rust core + CLI (tducks) + TypeScript web
  • iframe widgets, deny-by-default permissions
  • AGPL-3.0-only

What it is not

  • No tokens, gas, or L1 bus
  • No mandatory global DHT
  • No “trust the relay with content”
  • Not production-hardened yet (M5 MVP with caveats)

Get started

git clone https://github.com/Everwood-Technologies/thunderducks.git
cd thunderducks
cargo test --workspace
cargo run -p tducks -- serve --bind 127.0.0.1:8788
# other terminal
cargo run -p tducks -- --rpc http://127.0.0.1:8788 smoke
./scripts/dev-harness.sh
